- jpeg 큰놈을 짠짠바리로 바꾸기 [OK]
- canvas 드시고계신거 다 없애버리기 [OK]
- 기능 설정 -> 고장진단을 prewarm 생명주기에서 빼고 하기 전에는 아예 drop해서 엄청 느리지만 안전하게 (최후의 옵션) [LATER]
- ram partition을 나누어서 아예 따로 관리 (backup/ram-allocator 브랜치 확인 : PSRAM이 아예 여유가 없어서 decoder가 사용하는 버퍼 + 이미지 버퍼 두개를 공용하지 않으면 자리가 모자람. 디코더를 이미지버퍼에 땡겨오니 lvgl에서 썼다 말았다 하면서 auth없는 free하니까 크래쉬남. 일단 지금은 이 방식은 못 건드리겠음.) [LATER]
- image buffer의 크기는 알고있으니까, buffer 할당을 램 파티션의 뒤쪽에서부터 오게 하기
